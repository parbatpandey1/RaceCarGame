# RaceCarGame

A fast-paced SFML-based racing game featuring pseudo-3D graphics. Choose between a normal car or a police car, dodge opponents, and use boosts to navigate a winding, hilly road. Immerse yourself in an engaging experience with smooth controls, dynamic scenery, sound effects, and a vibrant UI—including menu navigation, car selection, and a game-over screen. Race your way to a high score while avoiding collisions!

---

## Features

- **Pseudo-3D Graphics:** Realistic, visually appealing rendering for an immersive racing experience.
- **Multiple Car Options:** Drive as a normal or police car, each with unique visual and gameplay styles.
- **Boost Mechanic:** Gain speed bursts to outpace rivals—use them wisely!
- **Engaging Scenery:** Hilly terrain and curving paths that keep the gameplay dynamic.
- **Smooth Gameplay:** Tight, responsive controls and fluid frame rates.
- **Audio Effects:** Background music and sound effects that enhance immersion.
- **Intuitive UI:** Includes a main menu, car selection screen, and game-over display.

## Getting Started

### Prerequisites

- **SFML** (Simple and Fast Multimedia Library) – ensure SFML is installed and properly linked.  
- A C++17–compatible compiler (e.g., GCC, Clang, MSVC).  
- **CMake** for building the project.

### Installation Steps

1. **Clone the repository**

   ```bash
   git clone https://github.com/parbatpandey1/RaceCarGame.git
   cd RaceCarGame
2. **Build the project**
   ```bash
   mkdir build && cd build
   cmake ..
   cmake --build .
3. **Run**
./RaceCarGame
